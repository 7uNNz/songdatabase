# PK曲庫 — 可自行架設的原始碼

包含目前 264 首歌曲資料、React 介面、SQLite 後端及編譯好的 dist。訪客可搜尋與閱讀；新增、修改、刪除時需要管理密碼。

## 啟動

安裝 Node.js 24（或至少 22.13）。將 `.env.example` 複製成 `.env`，把 `ADMIN_PASSWORD` 換成自己的密碼（至少 12 字元）。在此資料夾執行：

```sh
npm start
```

開啟 http://localhost:3000。已包含編譯結果，直接啟動不需安裝前端套件。

## 修改介面

```sh
npm install
npm run build
npm start
```

介面在 `src/App.tsx`、`src/styles.css`；後端在 `server/`。開發時先啟動後端，再於另一個終端執行 `npm run dev`。

## 給別人使用

把整個資料夾放到支援 Node.js 的伺服器，設定管理密碼後執行 `npm start`，透過 HTTPS 反向代理連到 3000 埠。HTTPS 上線後設定 `COOKIE_SECURE=1`。反向代理需保留 Host 與 Origin。也可用提供的 Dockerfile 建置，並掛載 `/app/data` 做永久儲存，透過環境變數提供 `ADMIN_PASSWORD`。

這是有後端的網站，不能只把 HTML 放到靜態主機。啟動服務即可讓訪客查看歌庫；管理密碼只交給管理者。

## 歌曲資料

第一次啟動會從 `data/songs.json` 匯入 264 首歌曲，之後寫入 `data/songs.sqlite`。更新程式請保留整個 data 資料夾。備份前先停止程式，再複製 data 資料夾。JSON 是匯出時的資料快照，後续編輯不會同步回 JSON。

管理登入有效 8 小時；服務重啟後需要重新登入。歌詞上限 500 字。少量歌曲已有歌詞，其餘可自行補上。

## 歌曲播放連結

這批圖片的 52 首歌曲已加入播放參考，資料在 `src/song-references.json`。同一作品優先連到原唱；同名異曲與改詞版本另作註記。點選歌曲後可開啟 YouTube。這批 52 首播放連結皆限 YouTube，部分影片可能受地區限制。副歌時間尚未核實的會明確標示；沒有自動播放，也沒有下載或附上未授權副歌歌詞。

## 歌手瀏覽

可直接點選歌手篩選歌曲，再輸入歌名縮小結果。電腦版使用側邊選單，手機版使用橫向歌手按鈕。歌手清單與數量隨歌曲新增或刪除更新。

合唱歌曲會歸入每位歌手的分類，例如「吳青峰 / 胡夏」同時列在吳青峰和胡夏底下。歌手數量按各自參與的歌曲計算，合唱署名保留。

## 自訂 YouTube 連結

編輯歌曲可貼上 YouTube 影片網址，也接受 youtu.be 短網址。有效網址儲存後顯示播放按鈕；清空網址並儲存會隱藏按鈕。原有的 52 首參考網址會預填，其他歌曲可自行補上。網址會存入 SQLite，舊資料庫啟動時自動新增欄位並保留原資料。介面採深藍灰漸層，已收錄歌詞顯示綠燈。

歌曲編輯包含「備註」欄位，最多 500 字，可修改版本說明或清空隱藏。現有資料庫啟動時會自動加入欄位，保留原有歌曲與歌詞。
